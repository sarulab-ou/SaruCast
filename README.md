# SaruCast

Windows 11の画面とPCの再生音声を、Google Cast対応テレビへ送るアプリです。テレビと共有する画面を選び、「キャスト開始」を押すだけで共有できます。ChromeやEdgeの起動・自動操作は使いません。

**[ダウンロード（Windows x64・ZIP）](https://github.com/sarulab-ou/SaruCast/releases/download/v0.1.4/SaruCast-win-x64.zip)** · [使い方](#使い方) · [MITライセンス](LICENSE)

現在のバージョンは**0.1.4（未署名の試用版）**です。アプリ内更新は0.1.4から利用できます。テレビ内蔵のミラーリング機能へ**Cast Streaming**で直接送信します。標準は**1080p上限・15fps・SDR**です。

## できること

- **テレビを選んで画面共有。** 同じLANのGoogle Cast機器を自動検索します。テレビへの専用アプリやカスタムReceiverの導入は不要です。
- **PCの音声も一緒に。** 既定の再生デバイスの音を送ります。音声を送らずに画面だけを共有する設定もあります。マイクは使いません。
- **共有する画面を選べる。** モニター単位で共有し、マウスカーソルも送ります。
- **画質を切り替え。** 1080pを上限とし、720pへ下げられます。フレームレートは15fpsが標準で、5／30fpsも選べます。縦横比を保ち、元の画面より大きく引き伸ばしません。
- **GPU・ソフトウェアを選べる。** 通常はGPUで映像をエンコードし、詳細設定でソフトウェア方式へ切り替えられます。
- **設定を記憶。** 前回のテレビ・画面・音声・画質設定を保存します。アプリを開いただけで共有を始めることはありません。
- **遅延の蓄積を抑える（0.1.3）。** 送信待ちの古い映像を破棄します。処理遅れや受信待ちが増えた場合は映像・音声の配信を作り直し、クリアした理由を画面の「配信ログ」に表示します。
- **ボタンから更新（0.1.4）。** GitHubの新しい公開リリースを確認し、更新ボタンからダウンロード・適用・再起動できます。ZIP版とインストーラー版に対応します。
- **追加ランタイムのインストール不要。** 必要なランタイムとFFmpegをZIPに同梱します。初回起動時の依存部品ダウンロードもありません。

## ダウンロード・起動

**[SaruCast v0.1.4 Windows x64 ZIPをダウンロード](https://github.com/sarulab-ou/SaruCast/releases/download/v0.1.4/SaruCast-win-x64.zip)**

v0.1.4をプレリリース（試用版）として配布しています。[リリースノート](https://github.com/sarulab-ou/SaruCast/releases/tag/v0.1.4) · [SHA-256チェックサム](https://github.com/sarulab-ou/SaruCast/releases/download/v0.1.4/SaruCast-win-x64.zip.sha256) · [ソースからのビルド](docs/build.md)

リポジトリが非公開の場合、ダウンロードにはアクセス権のあるGitHubアカウントでのログインが必要です。開発時のローカル出力は`artifacts/SaruCast-win-x64.zip`です。

1. `SaruCast-win-x64.zip`をダウンロードし、**Windows 11 x64**のPCに保存します。
2. ZIPを**全体展開**します。
3. 展開先の最上位にある**SaruCast.exe**をダブルクリックします。

**ZIP版が主な配布形式です。** DLLや`tools`などの同梱ファイルをそのまま保ってください。EXEだけを別の場所へ移すと動作しません。.NET Runtime、Visual C++ Runtime、FFmpeg、Bonjourなどを別途インストールする必要はありません。アプリによる自己展開もありません。

旧版から手動更新する場合は、SaruCastを終了してから、新しいZIPを別のフォルダーへ全体展開してください。画面下部に`0.1.4`と表示されることを確認します。設定はユーザーフォルダーに保存するため、展開先を変えても引き継ぎます。

配布物は未署名の試用版です。起動時にWindowsの警告が表示される場合があります。署名によってSmartScreenなどの警告が必ずなくなるとは保証しません。

### ショートカットが必要な場合：インストーラー版

[**SaruCast-Setup-win-x64.exeをダウンロード**](https://github.com/sarulab-ou/SaruCast/releases/download/v0.1.4/SaruCast-Setup-win-x64.exe) · [SHA-256](https://github.com/sarulab-ou/SaruCast/releases/download/v0.1.4/SaruCast-Setup-win-x64.exe.sha256)

セットアップを実行すると、現在のユーザー用にインストールし、**スタートメニューとデスクトップの両方**にSaruCastのショートカットを作成します。標準の保存先は`%LOCALAPPDATA%\Programs\SaruCast`です。通常は管理者権限を必要としません。必要なDLL・ランタイム・FFmpegを含み、初回ダウンロードはありません。

更新はインストール先のSaruCastを終了してから、同じ場所へセットアップを実行します。Windowsの「設定 → アプリ → インストールされているアプリ」またはスタートメニューの「SaruCast → アンインストール」から削除できます。設定・ログと、インストール先へ自分で追加したファイルは残します。

ZIP版とインストーラー版は同じアプリです。ZIP版の展開先に上書きインストールせず、別の場所に置いてください。両者は同じユーザー設定を使います。既存の同名ショートカットがある場合は、名前を変更してからセットアップを実行してください。

### アプリから更新する（0.1.4以降）

起動時にGitHubのリリース情報を確認します。画面右上の**更新を確認**でも再確認できます。新しい版があると**v○○に更新**へ変わるので、キャストを停止してから押してください。ダウンロード、SHA-256の照合、適用の準備を行い、アプリを終了して更新後に再起動します。ダウンロード中は**中止**できます。クリック前に更新ファイルを自動ダウンロードすることはありません。

ZIP版は同じフォルダー内のアプリと同梱部品を更新し、利用者が追加したファイルとユーザーフォルダーの設定・ログを保ちます。ZIP版で置換に失敗した場合は、置換済みファイルをバックアップから戻します。インストーラー版は同じインストール先へ新しいセットアップを実行し、Windowsのアプリ登録とショートカットも更新します。再起動後は**配信ログ**に更新結果を表示します。自動でキャストを始めることはありません。

最初の1回だけ、更新機能付きの0.1.4以降をZIPまたはセットアップで導入してください。0.1.3以前には更新ボタンがありません。書き込み権限がない場所や、リンクで参照したアプリフォルダーは自動更新せず、手動更新を案内します。自動更新は通常権限で使い、管理者として起動した場合はいったん終了して通常起動し直してください。配信中や、別のSaruCastが同じフォルダーから動いている間は更新できません。

更新確認は`sarulab-ou/SaruCast`の公開済みリリースを対象とします。現在配布している数値タグ（例：`v0.1.5`）の試用版も含み、未公開の下書き、同じ版、古い版は適用しません。通信に失敗した場合はアプリをそのまま使えます。更新にはGitHubと配布用CDNへのHTTPS通信が必要で、アカウントやトークンの設定は不要です。

## 使い方

1. PCとテレビを同じ信頼できるLANへ接続し、SaruCastを開きます。
2. **送信先テレビ**と**共有する画面**を選びます。テレビが一覧にない場合は**再検索**を押します。
3. 音も送りたい場合は**PCの音声も送る**を選びます。
4. **キャスト開始**を押し、テレビに映像が出るまで待ちます。接続準備中は同じボタンでキャンセルできます。
5. 共有を終えるときは**キャスト停止**を押します。

「配信中」は映像フレームの受信完了通知がテレビから続けて届いたことを確認して表示します。映像と音が実際に出ていることもテレビで確認してください。切断・スリープ・既定の音声再生先の変更後は、必要に応じてもう一度開始します。自動で共有を再開することはありません。

0.1.3では、送信待ちがあふれたり250msを超えて古くなった場合、古い映像と、それを参照する後続フレームを破棄して次のキーフレームから再開します。エンコーダーの時刻の遅れ・映像の受信確認待ち・テレビが通知する再生バッファのいずれかが約1秒を超えた状態で500ms続く場合は、配信中の映像と音声をいったん止めて作り直します。その際は一時的に映像・音声が途切れます。起動後5秒間は準備時間として監視判定から除きます。これは実際の画面表示の遅れを測る機能ではなく、表示遅延1秒以内を保証するものではありません。

クリア時は**配信ログ**が自動で開き、発生時刻・理由・再開確認を表示します。画面には直近100件を保持し、同じ内容を診断ログにも保存します。自動再作成は配信中のバッファ対策だけに限定します。1分以内に3回行っても遅延の増加が続く場合は停止するので、15fpsまたは720pへ下げて再開始してください。

## 詳細設定

| 項目 | 使う場面 |
| --- | --- |
| テレビのIPv4アドレス・接続確認 | 自動検索で見つからないテレビへ接続するとき |
| 画質 | 動作が重い、映像が途切れる場合に720pへ下げるとき |
| フレームレート | 通常は15fps。動きの少ない画面は5fps、滑らかさを優先する場合は30fps |
| GPUで映像をエンコード | GPU方式で映像を準備できない場合に、チェックを外してソフトウェア方式を試すとき |
| 画面取得をGDIに変更 | 通常の画面取得で問題がある場合に、別の取得方式を試すとき |
| 診断ログ | 接続や配信に失敗した原因を調べるとき |
| ライセンス | 同梱するソフトウェアのライセンス・通知を読むとき |

## ネットワークと接続できないとき

ゲストWi-Fiの端末分離、VPN、組織のネットワーク方針によって、同じLANでも接続できない場合があります。まずテレビの電源、PCとテレビの接続先、VPNの有無を確認してください。

Windowsが通信許可を求めた場合は、使用する信頼できるネットワークでSaruCastの受信を許可します。通常はPrivateプロファイルですが、信頼しているLANがPublicに分類されている場合もあります。現在のネットワークの許可が必要です。EXEの展開先を変えると、既存のアプリ許可が一致しなくなる場合があります。

管理対象PCでは、必要に応じて管理者へ次の通信範囲を相談してください。通常の実行に管理者権限やサービスの常駐は必要ありません。

| 用途 | 通信 |
| --- | --- |
| テレビの自動発見 | LANへのUDP 5353の照会と応答 |
| Cast制御 | テレビへのTCP 8009。自動発見で別ポートが通知された場合はそのポート |
| 映像・音声の配信 | テレビが通知した動的UDPポートへの送信と、その相手からの応答 |

映像と音声は暗号化したUDPで選択したテレビへ送ります。HLSやHTTPサーバーは使用しません。Firewallやセキュリティ機能を全面的に無効化する必要はありません。

## 対応範囲と制限

- **低遅延の直接配信です。** 利用者の実機確認では、音声オフの15fps配信が表示され、遅れは許容範囲との報告を得ました。表示遅延の秒数は未実測で、約1秒という目標の達成は保証しません。
- **SDRのモニター共有に対応します。** HDR入力の変換、個別ウィンドウ共有、保護コンテンツの制限回避は対象外です。HDR表示はWindows側でオフにしてください。
- **映像・音声はLAN内で転送します。** テレビ標準のCast機能の起動などに必要な外部通信もあるため、完全オフライン動作は保証しません。
- **信頼できるLANで使ってください。** 現在はCast機器の自己署名TLSを許容し、device-auth証明書の検証は未実装です。
- **実機確認は限定的です。** 0.1.2では検証先「オフィス」で、Cast Streamingの実画面（音声オフ）と、テスト映像・確認音の再生を利用者が確認しました。0.1.3のテレビ実機試験は未実施です。テレビのメーカー・機種は未確認です。
- 30分の診断配信は完了しました。エンコーダーのメモリ増加を観測しており、長期安定性は未判定です。音ずれの実測、ChromeのGPUアクセラレーションONでの個別の受け入れ試験、複数モニター・複数NIC・別機種テレビなどは未検証です。詳細は[検証記録](docs/verification.md)を参照してください。

## 設定とデータの保存先

設定と診断ログは`%LOCALAPPDATA%\SaruCast`に保存します。EXEの置き場所への書き込みは必要ありません。ログを外部へ自動送信することはありません。

配信用の動画ファイルは保存せず、メモリとパイプを介して送信します。旧版で残った一時セッションは、2日経過後の起動で整理します。診断ログは14日を過ぎると起動時に削除します。

## 開発

C#、.NET 10 LTS、WPFで実装しています。画面取得はDXGI Desktop Duplication、PC音声はNAudioを使ったWASAPI loopback、映像はFFmpegとWindows標準のMedia FoundationでH.264へ、音声はConcentusでOpusへエンコードします。Cast StreamingのRTP/RTCP・交渉モデル・OpusアダプターはApache-2.0のClassic Chromecast casterから必要な部分を取り込んでいます。

```powershell
./scripts/bootstrap.ps1
./scripts/publish.ps1 -RebuildFfmpeg
```

SDKは作業フォルダー内へ取得します。FFmpegのビルドにはWSL UbuntuとMinGW-w64などの開発ツールが必要です。これらはアプリを使うPCには不要です。2回目以降、FFmpegを作り直さない場合は`./scripts/publish.ps1`だけで発行できます。

発行はWindows x64向けの自己完結型ZIPです。`SelfContained=true`を維持し、`PublishSingleFile=false`、trimming・NativeAOTなしで必要な発行出力をすべて同梱します。依存物は[固定バージョン一覧](dependencies.json)とNuGetのlockファイルで管理します。
